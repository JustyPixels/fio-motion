# Fio Motion

## 1. 小さな探検家に会おう

スペースキーでサンプルの手振りを再生します。画像はレイヤーに分かれ、右腕にはリグがあります。

## 2. 画像にコントロールを追加

Rigでレイヤーと移動ピンを選びます。動かしたくない場所に固定ピンを追加し、ピンをドラッグして曲がり方を確認します。

## 3. ポーズを作って動かす

アニメーションで自動キーを有効にし、再生ヘッドを動かして手のピンをドラッグします。滑らかな補間が自動で適用されます。

## 4. タイミングを調整

タイムラインのひし形を選びます。時間カーブで加速を、軌道ハンドルで動きの経路を調整します。

## 5. ショットを物語にする

構成ではショットと音声をまとめます。完成したらMP4または透明PNG連番で書き出します。

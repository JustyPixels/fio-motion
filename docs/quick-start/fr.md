# Fio Motion

## 1. Découvrez votre petit explorateur

Appuyez sur Espace pour lire le salut. L’illustration est en calques et le bras droit possède déjà un rig simple.

## 2. Ajoutez des contrôles à l’illustration

Ouvrez Rig, sélectionnez un calque et un point de mouvement. Ajoutez un ancrage aux zones fixes, puis faites glisser les points pour tester la flexion.

## 3. Créez une pose, puis une autre

Ouvrez Animer avec la clé automatique activée. Déplacez la tête de lecture et le point de la main, puis lancez la lecture. Le mouvement est adouci automatiquement.

## 4. Personnalisez le rythme

Sélectionnez un losange dans la chronologie. Ajustez les poignées temporelles pour l’accélération ou les poignées spatiales pour la trajectoire.

## 5. Transformez les plans en histoire

Assembler réunit plans et audio dans une chronologie. Exportez ensuite un MP4 ou une séquence PNG transparente.

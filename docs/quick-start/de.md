# Fio Motion

## 1. Lernen Sie Ihren kleinen Entdecker kennen

Drücken Sie die Leertaste für das Winken. Die Grafik besteht aus Ebenen; der rechte Arm hat ein einfaches Rig.

## 2. Grafik mit Steuerelementen versehen

Öffnen Sie Rig und wählen Sie Ebene und Bewegungs-Pin. Setzen Sie einen Anker an festen Stellen und ziehen Sie Pins zum Testen.

## 3. Eine Pose, dann die nächste

Öffnen Sie Animieren mit Auto-Key. Versetzen Sie die Abspielposition und ziehen Sie den Hand-Pin. Die Bewegung wird automatisch geglättet.

## 4. Timing gestalten

Wählen Sie eine Raute in der Zeitleiste. Zeitkurvengriffe ändern die Beschleunigung; räumliche Griffe ändern den Pfad.

## 5. Szenen zu einer Geschichte verbinden

Zusammenstellen verbindet Szenen und Audio. Exportieren Sie anschließend MP4 oder eine transparente PNG-Sequenz.

# Fio Motion

## 1. Conoce a tu pequeño explorador

Pulsa Espacio para reproducir el saludo. La ilustración tiene capas y el brazo derecho ya tiene un rig sencillo.

## 2. Añade controles a la ilustración

Abre Rig, selecciona una capa y elige Pin de movimiento. Añade un Ancla donde la ilustración deba quedar fija. Arrastra los pins para probar la flexión.

## 3. Crea una pose, luego otra

Abre Animar con la clave automática activada. Mueve el cabezal, arrastra el pin de la mano y reproduce. El suavizado se aplica automáticamente.

## 4. Ajusta el ritmo

Selecciona un rombo en la línea de tiempo. Arrastra los controles de curva para ajustar la aceleración o añade controles espaciales para cambiar la trayectoria.

## 5. Convierte escenas en una historia

Montar reúne escenas y audio en una línea de tiempo. Al terminar, exporta MP4 o una secuencia PNG transparente.

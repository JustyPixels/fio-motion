# Fio Motion 1.0 RC 2

The purple puppet icon from the website now appears throughout the app: in the editor, welcome screen, loading screen and window icon. The version label also updates with each build.

This update includes the MIT license in the Windows packages. Your existing .puppet projects still work; the project format and animation tools haven't changed.

**Downloads:** use the installer for a normal setup, or choose the portable version to run without installing. The support archive has example characters and offline guides. SHA256 checksums are included.

These builds are **unsigned**, so Windows may show a trust or SmartScreen warning. RC 2 is still a test version; clean Windows 11 and independent artist testing are pending.

## Testing status

RC 2 is a small branding and packaging update. The [acceptance notes](ACCEPTANCE.md) record earlier animation, rendering and recovery checks and identify which results belong to RC 1. The support archive contains the checks performed for this build.

Clean Windows 11 installation and display-scaling tests, reference-hardware performance, independent artist/usability tests, language review and brand review remain pending. Some diagnostics fall back to English. Shared skeleton structural edits are managed through the assistant.

# Fio Motion — quick start



Start with **Learn with the example**, or choose **New project** and a 16:9, 4:3, 1:1, 9:16 or custom canvas. The viewer keeps the project proportions as you resize the window.



1. Import artwork in **Rig**. Use transparent PNG parts or a prepared layered PSD. Read import compatibility notices.

2. Select **Humanoid assistant**. Associate the torso, head and whole or segmented limbs. Existing animated or rigged pieces require **Work on a copy**. Place the joints, test movement and apply. Cancel leaves the project intact.

3. Use **Connect** for accessories or free-form characters. Select pieces and click a destination layer, pin or bone. Drawing order stays in the Layers tree; rig links appear in Characters.

4. In **Animate**, a canvas click selects the connected character; double-click enters a piece and Escape returns. Select visible controls directly. Auto-key starts enabled: move the playhead, pose and play. Rig edits never create animation keys.

5. Select keys by click, additive selection or a box. Ctrl+C/V copies keys; Ctrl+Shift+C/V copies a pose. Ctrl+D duplicates selected keys or the character. Paste aligns the earliest copied key to the playhead. Alt temporarily bypasses snapping during retiming. Timing curves control speed; spatial handles control the route.

6. Arrange shots and audio in **Assemble**. Open Export and add a shot, range or production to the render queue. MP4 includes sequence audio; PNG supports transparency. The beta and 1.0 candidate have no feature locks.



F2 or the context menu renames a layer directly. Shift selects a layer range; Ctrl toggles individual layers. Preferences controls language, optional update notices and Restore layout. Resize the panel borders or collapse panels from their labels.



Closing modified work offers Save, Discard and Cancel. A cancelled or failed save keeps the application open. Save a project explicitly and keep its `.assets` folder beside the `.puppet` manifest. Collect project creates a portable archive. Existing beta recovery stays available after renaming.

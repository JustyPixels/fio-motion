# Fio Motion

Offline 2D character animation for Windows 11 x64.

Download the installer or portable build from [Releases](https://github.com/JustyPixels/fio-motion-releases/releases).

Projects use the .puppet format. Existing Puppet Studio projects remain readable. Editing is offline; update notifications are optional. All features are unlocked.

Release candidates are for testing. Version 1.0.0-rc.1 is unsigned, as authorized by the publisher; Windows may display trust or SmartScreen warnings. No certificate publisher identity is claimed. See the included qualification report for pending checks.

Languages: Português brasileiro, English, Español, Français, Deutsch, 日本語, 简体中文.

Report problems with the app version, Windows version, GPU, steps to reproduce, and an optional collected example project. Do not post private artwork publicly.
